# Expressive control (emotion, non-verbals, style instructions, voice design) in open-weight TTS, and how to label an unlabeled corpus — state as of 2026-10-26

Scope note: open-weight systems and open tools only; closed APIs appear only as benchmark baselines (gpt-4o-mini-tts in EmergentTTS-Eval, Gemini-TTS in InstructTTSEval, Eleven v4 on the Speech Arena). All dates/versions are as stated by the cited source. Where sources conflict, both are given.

## KQ1. Mechanisms per model: how do open models control emotion, non-verbals, style and voice identity, and how were they trained to do it?

### Takeaway
Four mechanism families coexist in 2024–2026 open models: (a) inline tags/markers learned as tokens in the transcript (Orpheus, Fish S1-mini/S2-pro, Bark, Dia, Chatterbox Turbo, Step-Audio-EditX, CosyVoice 3 vocal bursts); (b) natural-language instructions prepended to the text and learned as ordinary language-modeling (CosyVoice 3, Qwen3-TTS, VoxCPM2, EmoVoice, Parler-TTS, Step-Audio-EditX); (c) explicit emotion embeddings/vectors disentangled from timbre (IndexTTS2 with GRL, Zonos 8-dim vector / Zonos2 additive direction vectors, Vevo content-style tokens); (d) inference-time knobs (Chatterbox exaggeration/cfg_weight, Zonos2 emotion_strength/emotion_cfg_scale). Text-described voice design (new voice, no reference) is only documented for Qwen3-TTS-VoiceDesign, VoxCPM2, Parler-TTS (coarse attributes), Higgs Audio v2 (scene/speaker traits), and partly Bark ([MAN]/[WOMAN] bias); CosyVoice 3 explicitly cannot control timbre by text.

### Cited Findings

**Inline-tag models**
- Orpheus-TTS (Canopy Labs): Llama-3B backbone, "trained on 100k+ hours of English speech data", emotive tags `<laugh>`, `<chuckle>`, `<sigh>`, `<cough>`, `<sniffle>`, `<groan>`, `<yawn>`, `<gasp>`; Apache-2.0; 1B/400M/150M variants listed as unreleased; multilingual research release has "7 pairs of pretrained and finetuned models" (languages not named on the README) — [Orpheus-TTS GitHub](https://github.com/canopyai/Orpheus-TTS)
- Orpheus tags are "treated as special tokens by Orpheus's tokenizer" and "during training, the model will learn to associate these tags with the corresponding audio patterns" (third-party guide, not in the official repo) — [Unsloth TTS fine-tuning guide](https://unsloth.ai/docs/basics/text-to-speech-tts-fine-tuning)
- Fish OpenAudio S1-mini: 0.5B distilled from the proprietary 4B S1; "trained on more than 2 million hours of audio"; CC-BY-NC-SA-4.0; 13 languages (EN, ZH, JA, DE, FR, ES, KO, AR, RU, NL, IT, PL, PT — no Turkish); 51 emotion markers (angry, sad, excited, … amused), 5 tone markers (in a hurry tone, shouting, screaming, whispering, soft tone), 10 special markers (laughing, chuckling, sobbing, crying loudly, sighing, panting, groaning, crowd laughing, background laughter, audience laughing), with onomatopoeia "Ha,ha,ha" / "Hmm,hmm"; Seed-TTS Eval EN WER 0.008 (S1) / 0.011 (S1-mini) — [openaudio-s1-mini model card](https://huggingface.co/fishaudio/openaudio-s1-mini)
- Fish docs state all 13 S1 languages can use emotion markers; the parenthesis syntax is now described as the legacy (S1) syntax and S1 as deprecated — [Fish Audio emotion docs](https://docs.fish.audio/developer-guide/core-features/emotions); a third-party page claims S1 was succeeded by S2-pro on 2026-02-28 (unverified against Fish) — [nolist.ai](https://nolist.ai/item/speech-api-fish-audio-openaudio-s1)
- Fish Audio S2-pro (2026): ~5B BF16 (4B "Slow AR" + 400M "Fast AR"); Fish Audio Research License — research/non-commercial free, "Commercial use requires a separate license"; 80+ languages, Turkish listed as "tr"; control via inline free-form `[tag]` descriptions such as `[whisper in small voice]`, "15,000+ unique tags"; non-verbals listed: laughing, chuckling, sighing, inhaling, exhaling, panting, clearing throat, moaning, screaming, shouting (crying not listed); trained on >10M hours; RTF 0.195 on H200 — [fishaudio/s2-pro model card](https://huggingface.co/fishaudio/s2-pro)
- Fish S2 technical report: weights, fine-tuning code and SGLang engine released; "instruction-following control via natural-language descriptions"; staged data pipeline "covering video captioning, speech captioning, voice-quality assessment, and reward modeling" — [arXiv 2603.08823](https://arxiv.org/abs/2603.08823)
- Bark (Suno, released 2023-04-20, MIT since 2023-05-01): tags `[laughter]`, `[laughs]`, `[sighs]`, `[music]`, `[gasps]`, `[clears throat]`; "—"/"..." hesitations; "♪" lyrics; CAPITALS for emphasis; `[MAN]`/`[WOMAN]` speaker bias; 13 languages including Turkish, "English quality is best for the time being"; "may take some creative liberties"; no custom voice cloning — [Bark GitHub](https://github.com/suno-ai/bark)
- Dia (Nari Labs): 1.6B, Apache-2.0, "only supports English generation at the moment"; 21 non-verbal tags: (laughs), (clears throat), (sighs), (gasps), (coughs), (singing), (sings), (mumbles), (beep), (groans), (sniffs), (claps), (screams), (inhales), (exhales), (applause), (burps), (humming), (sneezes), (chuckle), (whistles); "use non-verbal tags sparingly" — unlisted tags "may cause artifacts"; `[S1]`/`[S2]` alternating speaker tags; cloning from 5–10 s reference (~86 tokens/s); Dia2 released "11/19" (year not shown); training data not described — [Dia GitHub](https://github.com/nari-labs/dia); Dia 1.6B was announced 2025-04-22 — [TechCrunch](https://techcrunch.com/2025/04/22/two-undergrads-built-an-ai-speech-model-to-rival-notebooklm/)
- Chatterbox (Resemble AI, MIT): `exaggeration` and `cfg_weight`, defaults 0.5/0.5; for "expressive or dramatic speech" use cfg_weight≈0.3 and exaggeration≥0.7; higher exaggeration speeds speech up; cfg_weight=0 may reduce accent carry-over across languages; Multilingual model lists Turkish (tr); Turbo and Nano accept paralinguistic tags `[cough]`, `[laugh]`, `[chuckle]` "and more"; third-party listening tests by Podonos vs ElevenLabs Turbo v2.5, Cartesia Sonic 3, VibeVoice 7B (no numbers on README); training hours not stated — [Chatterbox GitHub](https://github.com/resemble-ai/chatterbox)
- Step-Audio-EditX (StepFun, arXiv Nov 2025): "3B-parameter LLM-based Reinforcement Learning audio edit model" for iterative editing of emotion (Angry, Happy, Sad, Excited, Fearful, Surprised, Disgusted), speaking style and paralinguistics via inserted tags such as `[Laughter]`, `[Breathing]`; one editing pass raised an LLM-judge paralinguistic score (1–3) from 1.91 to 2.89; Cough/Crying/Stress tags and other languages are listed as future work — [Step-Audio-EditX GitHub](https://github.com/stepfun-ai/Step-Audio-EditX); [arXiv 2511.03601](https://arxiv.org/abs/2511.03601)

**Natural-language instruction ("instruct") models**
- CosyVoice 3 (Alibaba FunAudioLLM, arXiv May 2025): instruction text plus special token `<||endofprompt||>` is prepended to the input text; fine-grained tags such as `[laughter]`, `[breath]` and `<strong>…</strong>` emphasis; instruction data "from 1,500 hours to 5,000 hours" covering emotions, speed, tones, dialects, accents, role-playing, ">100 types"; total training data "expanded from ten thousand hours to one million hours"; 9 languages (ZH, EN, JA, KO, DE, FR, RU, IT, ES — no Turkish) plus 18 (abstract) / 19 (Sec. 4.2) Chinese dialects/accents; speech tokenizer multi-task-trained including emotion recognition; speaker SFT mixes target-speaker data with instruction data ("You are Speaker B. Please speak German."); the paper states CosyVoice 3 "cannot control acoustic characteristics, such as timbre, through textual instructions" — [arXiv 2505.17589v2](https://arxiv.org/html/2505.17589v2)
- Qwen3-TTS (Qwen team, arXiv Jan 2026): 0.6B and 1.7B; "over 5 million hours of speech data spanning 10 languages" (ZH, EN, DE, IT, PT, ES, JA, KO, FR, RU — no Turkish); 12.5 Hz tokenizer, 16 quantizer layers (1 semantic + 15 acoustic RVQ), codebook 2048; instructions prepended to the input in ChatML, treating voice control "as a language modeling task"; a "probabilistically activated thinking pattern" used in training to improve instruction following; Qwen3-TTS-12Hz-1.7B-VD generates novel voices from text descriptions; Apache 2.0; how voice-design training descriptions were produced is NOT described — [arXiv 2601.15621 (HTML)](https://arxiv.org/html/2601.15621); released 2026-01-15 per the Qwen blog, which claims it beat MiniMax-Voice-Design on InstructTTS-Eval — [Qwen blog](https://qwen.ai/blog?id=qwen3tts-0115); VoiceDesign checkpoint uses `generate_voice_design(text, language, instruct=...)` — [Qwen3-TTS GitHub](https://github.com/QwenLM/Qwen3-TTS)
- VoxCPM2 (OpenBMB, arXiv 2026-06-05): ~2B, MiniCPM-4 backbone, Apache 2.0; 30 languages + 9 Chinese dialects, Turkish included (MiniMax-MLS-Test WER 0.82, SIM 87.1; internal 30-language benchmark WER 1.65); voice design "generates entirely new voices from free-form text descriptions without any reference audio" (age, gender, accent, vocal texture, scenario) placed as a text prefix; controllable cloning = reference clip for identity + style description prefix (emotion, rate, pitch, energy, emphasis), "requiring no additional embedding modules" — [arXiv 2606.06928v1](https://arxiv.org/html/2606.06928v1); VoxCPM v1 (Sept 2025) is tokenizer-free, trained end-to-end with a diffusion objective — [arXiv 2509.24650](https://arxiv.org/html/2509.24650v1); repo Apache-2.0 — [VoxCPM GitHub](https://github.com/OpenBMB/VoxCPM)
- EmoVoice (arXiv Apr 2025, ACM MM 2025): Qwen2.5-0.5B / 1.5B LLM autoregressively predicts 50 Hz CosyVoice semantic tokens (3 per step), decoded by CosyVoice flow-matching + HiFi-GAN; free-style emotion description is plain text in the prompt `"<SYSTEM>: Say this sentence with emotion of <Description>. \n <Text>"` with no dedicated prompt encoder; EmoVoice-PP variant predicts phoneme tokens in parallel for content consistency — [arXiv 2504.12867v3](https://arxiv.org/html/2504.12867v3)
- Parler-TTS (Hugging Face): speech features "gender, background noise, speaking rate, pitch and reverberation" controlled by a text description — [parler-tts-mini-v1](https://huggingface.co/parler-tts/parler-tts-mini-v1); the Data-Speech pipeline measures continuous acoustic variables, bins them into keywords (pitch compared against same-gender speakers) and generates natural-language descriptions; requires gender and speaker-id columns — [dataspeech GitHub](https://github.com/huggingface/dataspeech)
- VoxInstruct appears only as a weak baseline in InstructTTSEval (ZH 47.5/52.3/42.6, EN 54.9/57.0/39.3 APS/DSD/RP) — [arXiv 2601.15621](https://arxiv.org/html/2601.15621)

**Explicit emotion embedding / disentangled reference models**
- IndexTTS2 (arXiv June 2025; AAAI 2026): emotion embedding from a style prompt via a Conformer "emotion perceiver"; seven emotions {Anger, Happiness, Fear, Disgust, Sadness, Surprise, Neutral} each with precomputed embedding sets; a Text-to-Emotion (T2E) module (distilled Qwen3-1.7B, LoRA-trained on DeepSeek-R1 outputs) maps a natural-language description to a 7-way distribution whose probability-weighted average of the emotion embeddings becomes the control vector; a Gradient Reversal Layer with a speaker classifier removes speaker information from the emotion embedding; trained on 55K hours (30K ZH + 25K EN) with a 135-hour emotional subset (361 speakers; 29 h from ESD, the rest "commercial purchases"); three stages (full data → emotion refinement on the 135 h with speaker conditioner frozen + GRL → full-data robustness fine-tune); languages ZH/EN — [arXiv 2506.21619](https://arxiv.org/html/2506.21619); IndexTTS-2.5 keeps "cross-lingual and timbre-emotion disentanglement" and runs faster — [index-tts GitHub](https://github.com/index-tts/index-tts); [AAAI paper](https://ojs.aaai.org/index.php/AAAI/article/view/40820/44781)
- Zonos-v0.1 (Zyphra, beta Feb 2025): trained on >200k hours multilingual speech; conditioning on speaking rate, pitch std, audio quality and emotions — [Zyphra release post](https://www.zyphra.com/our-work/beta-release-of-zonos-v0-1); 8-dimensional emotion vector (happiness, sadness, disgust, fear, surprise, anger, other, neutral) — [Clore guide](https://docs.clore.ai/guides/audio-and-voice/zonos-tts); speaker embedding from a ResNet293 encoder → LDA → compressed 256→128 dims — [Zonos-v0.1-speaker-embedding](https://huggingface.co/Zyphra/Zonos-v0.1-speaker-embedding)
- Zonos2 (Zyphra, 2026): open-weight MoE TTS "trained on more than 6 million hours"; MIT; emotions "applied as additive direction vectors on speaker conditioning, with no checkpoint changes" (e.g. happy, sad, angry, surprised; full list from `GET /tts/capabilities`), plus valence (−1…+1), arousal (−1…+1), `emotion_strength`, `emotion_cfg_scale`; ECAPA-TDNN speaker embedding, reusable `.npy`; language tiers: Tier 1 EN/ZH/JA, Tier 2 ten languages, Tier 3 21 languages — Turkish not listed; non-verbals not mentioned; no benchmark numbers on page — [Zonos2 GitHub](https://github.com/Zyphra/Zonos2/)
- Vevo (Amphion, ICLR 2025): "self-supervised disentanglement" with two tokenizers — a content tokenizer (vocab 32) and a content-style tokenizer (vocab 8192); variants Vevo-Timbre (style-preserved VC), Vevo-Style (accent/emotion conversion), Vevo-Voice, Vevo-TTS (style + timbre control); trained on Emilia (101k h), 6 languages (EN, ZH, DE, FR, JA, KO); license not stated — [Vevo README](https://github.com/open-mmlab/Amphion/blob/main/models/vc/vevo/README.md)
- Higgs Audio v2 (Boson AI): pretrained on ~10M hours ("AudioVerse") annotated by "multiple ASR models, sound event classification models, and an in-house audio understanding model" fine-tuned from Higgs Audio v1 Understanding; a `scene` role carries scene descriptions ("Audio is recorded from a quiet room.") and speaker traits ("SPEAKER0: feminine"); without speaker tags the model will "select a suitable voice on your own"; claims "melodic humming with the cloned voice" and "automatic prosody adaptation during narration"; license "other" — [higgs-audio-v2 model card](https://huggingface.co/bosonai/higgs-audio-v2-generation-3B-base); 3.6B LLM backbone + 2.2B audio adapter — [DeepWiki](https://deepwiki.com/boson-ai/higgs-audio); renamed Higgs TTS 2 — [higgs-tts-2-3b-base](https://huggingface.co/bosonai/higgs-tts-2-3b-base); as of Oct 2026 the GitHub landing page is for Higgs Audio v3: "Conversational TTS across 100+ languages", "inline emotion / style / prosody control", "Boson Higgs Audio v3 Research and Non-Commercial License" (while the repo About still lists Apache-2.0) — [higgs-audio GitHub](https://github.com/boson-ai/higgs-audio)

**Training-free / post-hoc control research (2025–2026)**
- EmoSteer-TTS: "training-free emotion-controllable TTS via activation steering" — [arXiv 2508.03543](https://arxiv.org/pdf/2508.03543)
- Sparse autoencoders for interpretable emotion control, using IndexTTS2 as backbone — [arXiv 2606.01479](https://arxiv.org/html/2606.01479v1); task-vector arithmetic for emotional expressivity in LM-based TTS — [arXiv 2606.05367](https://arxiv.org/pdf/2606.05367)

### Inferences
- Tag-based control is cheap to add by fine-tuning because tags are ordinary tokens in the transcript; instruction-based control needs paired (description, audio) data which every lab builds with audio-LLM captioners (see KQ3). Disentangled-embedding control (IndexTTS2/Zonos) needs emotion-labelled multi-speaker audio but gives emotion-from-one-clip, timbre-from-another.
- For a Turkish target, the only open models that both list Turkish and expose expressive control are: Chatterbox Multilingual (knobs), Fish S2-pro (free-form tags; non-commercial license), VoxCPM2 (instructions + voice design; Apache 2.0), Bark (tags; low quality outside English). CosyVoice 3, Qwen3-TTS, IndexTTS2, Orpheus, Dia and Zonos2 do not list Turkish.
- Qwen3-TTS and VoxCPM2 are the two open systems with documented text-only voice design and benchmark numbers (InstructTTSEval); CosyVoice 3 explicitly cannot.

### Gaps
- Qwen3-TTS does not disclose how its voice-design / instruction training labels were produced (only VoxCPM2 and Higgs describe their pipelines).
- Chatterbox training-data size and the Podonos win rates were not on the README; Chatterbox Turbo language coverage for tags not verified.
- Higgs Audio v3 (languages list, tag syntax, release date) could not be verified beyond the landing-page tagline; the v2 model card's release date is not stated.
- Whether Zonos2 can synthesize a random/designed voice without a reference is not stated.
- Step-Audio (Feb 2025 original Step-Audio-TTS-3B) and Kyutai/other 2026 entrants were not researched.

## KQ2. Which open models can produce real laughter / crying / sighing (not just "haha"), in which languages, and do non-verbal tags transfer to a new language after fine-tuning?

### Takeaway
Real non-verbal vocalizations are documented for Orpheus (EN; 8 tags), Fish S1-mini (13 languages; sobbing/crying loudly/sighing/laughing…), Fish S2-pro (80+ languages incl. Turkish; laughing/sighing/panting…, no crying listed), Dia (EN only; 21 tags), Bark (13 languages incl. Turkish, best in EN), Chatterbox Turbo/Nano ([laugh]/[chuckle]/[cough]), CosyVoice 3 ([laughter]/[breath] in 9 languages), Step-Audio-EditX ([Laughter]/[Breathing]). I found no published experiment showing that non-verbal tags learned in one language transfer to a new language after fine-tuning; the only data point is that ~3 h of tagged single-speaker English data suffices to (re)teach Orpheus laughs/sighs together with a new voice.

### Cited Findings
- Orpheus: `<laugh>`, `<chuckle>`, `<sigh>`, `<cough>`, `<sniffle>`, `<groan>`, `<yawn>`, `<gasp>`; English base, 7 multilingual pairs — [Orpheus-TTS GitHub](https://github.com/canopyai/Orpheus-TTS)
- Unsloth's Elise dataset (MrDragonFox/Elise) is "~3 hour single-speaker English" (~1,200 samples) with 336 occurrences of "laughs" and 156 of "sighs" embedded in transcripts; a tag-free variant exists (Jinsaryko/Elise); if a dataset lacks tags Unsloth suggests manually annotating transcripts where the audio contains those expressions — [Unsloth TTS guide](https://unsloth.ai/docs/basics/text-to-speech-tts-fine-tuning)
- Daniel Han (Unsloth): fine-tuning Orpheus "on a tiny dataset … changed the voice + personality of the model entirely … the model has emotional cues like giggling or sighing and you're able to customize that too by fine-tuning" — [X post](https://x.com/danielhanchen/status/1905315906051604595)
- Orpheus README advises against synthetic data for voice fine-tuning ("produces worse results … probably because synthetic voices lack diversity") — [Orpheus-TTS GitHub](https://github.com/canopyai/Orpheus-TTS)
- A community Bangla fine-tune of Orpheus-3B exists (no evidence on tag behaviour) — [EMTIAZZ/orpheus-3b-bangla-high-data-finetuning](https://huggingface.co/EMTIAZZ/orpheus-3b-bangla-high-data-finetuning)
- Fish S1-mini special markers include sobbing, crying loudly, sighing, panting, groaning, laughing, chuckling; 13 languages, no Turkish — [openaudio-s1-mini](https://huggingface.co/fishaudio/openaudio-s1-mini); all 13 languages can use emotion markers — [Fish docs](https://docs.fish.audio/developer-guide/core-features/emotions)
- Fish S2-pro: 80+ languages including Turkish; non-verbals laughing, chuckling, sighing, inhaling, exhaling, panting, clearing throat, moaning, screaming, shouting; crying not mentioned — [s2-pro model card](https://huggingface.co/fishaudio/s2-pro)
- Dia: 21 tags incl. (laughs), (sighs), (coughs), (screams), (humming), English only — [Dia GitHub](https://github.com/nari-labs/dia)
- Bark: `[laughter]`, `[laughs]`, `[sighs]`, `[gasps]`, `[clears throat]`, `[music]`; 13 languages incl. Turkish, "English quality is best" — [Bark GitHub](https://github.com/suno-ai/bark)
- Chatterbox Turbo/Nano: `[cough]`, `[laugh]`, `[chuckle]` "and more"; Multilingual lists Turkish (knob-based) — [Chatterbox GitHub](https://github.com/resemble-ai/chatterbox); a third-party review says exaggeration/CFG belong to the original model while Turbo/Nano rely on tags (unverified) — [oakgen.ai](https://oakgen.ai/blog/chatterbox-tts-open-source-review)
- CosyVoice 3: vocal bursts `[laughter]`, `[breath]` as fine-grained control in 9 languages — [arXiv 2505.17589v2](https://arxiv.org/html/2505.17589v2)
- Step-Audio-EditX: `[Laughter]`, `[Breathing]`; Cough/Crying listed as future; "other languages" as future — [Step-Audio-EditX GitHub](https://github.com/stepfun-ai/Step-Audio-EditX)
- Higgs Audio v2 card mentions humming but not laughter — [higgs-audio-v2 card](https://huggingface.co/bosonai/higgs-audio-v2-generation-3B-base)
- NonverbalTTS: a 17-hour English corpus (VoxCeleb + Expresso) with 10 NV types (e.g. laughter, coughs) and 8 emotion categories; fine-tuning open TTS on it reached "parity with the closed-source CosyVoice2" on speaker similarity and nonverbal fidelity — [arXiv 2507.13155](https://arxiv.org/abs/2507.13155)
- SMIIP-NV: a Mandarin multi-annotation non-verbal expressive corpus for LLM-based TTS (Duke Kunshan, 2025) — [SMIIP-NV PDF](https://sites.duke.edu/dkusmiip/files/2025/08/SMIIP_NV__A_Multi_Annotation_Non_Verbal_Expressive_Speech_Corpus_in_Mandarin_for_LLM_Based_Speech_Synthesis-2.pdf)
- Laugh-Now-Cry-Later (Microsoft) controls time-varying emotion in flow-matching TTS, but is a research paper, not an open release — [arXiv 2407.12229](https://arxiv.org/pdf/2407.12229)

### Inferences
- Because tags are transcript tokens, non-verbal production in a new language should mainly depend on (i) the base model having heard the acoustic event (laughter is language-independent) and (ii) having tagged Turkish examples; the Elise experiment (3 h, ~500 tag instances) is the best public indication of the order of magnitude, but it is single-speaker English and voice-plus-tags simultaneously.
- Crying/sobbing is the rarest documented non-verbal (only Fish S1-mini lists it; Step-Audio-EditX lists it as future), so a Turkish corpus will likely need explicit mining of cry/sob segments if that tag matters.

### Gaps
- No source reports a controlled experiment on cross-lingual transfer of non-verbal tags after fine-tuning (e.g., English-trained `<laugh>` reused in Turkish). Community Bangla/other Orpheus fine-tunes do not document tag behaviour.
- No per-language quality numbers for non-verbals in Fish S2-pro or Bark beyond "English best".

## KQ3. How do researchers label emotion and non-verbals at scale (emotion2vec, SenseVoice, Whisper-based detectors, audio captioners, dataset pipelines), what accuracy is reported, and does it work for Turkish / cross-lingually?

### Takeaway
Production pipelines in 2025–2026 (VoxCPM2, Higgs AudioVerse, Fish S2, LAION Emilia-with-Emotion) chain a cheap screener (emotion2vec+/SenseVoice-style classifier or sound-event tagger) with an audio-LLM captioner (Gemini 2.5 Pro, Step-Audio R1, Qwen3-Omni-Captioner, BUD-E Whisper) and optional expert checks for gender/age/emotion; human validation is used only for benchmarks. Reported quality is modest: EmpathicInsight-Voice reaches Spearman ≈0.42 vs expert raters (≈ Gemini 2.5 Pro), zero-shot 70.6% on EmoDB and 74.2% on RAVDESS; Qwen2-Audio ≈0.55 accuracy on MELD; emotion2vec showed 84% (EmoDB, German) and 91% (SUBESCO, Bangla) in-domain. No tool reports Turkish numbers; the only Turkish figure is a corpus-specific CNN at ~76% on TurEV-DB.

### Cited Findings

**Classifiers / taggers**
- emotion2vec (ACL Findings 2024): universality "validated across 18 emotional datasets spanning 10 languages"; 84.34% on EmoDB (German), 90.91% on SUBESCO (Bangla); best on all nine non-English datasets vs other SSL models — [ACL Anthology](https://aclanthology.org/2024.findings-acl.931.pdf); the authors' "language-independent emotional patterns" claim is interpretation of multilingual benchmarks, not a transfer test — [alphaXiv](https://www.alphaxiv.org/abs/2312.15185)
- emotion2vec+ (plus_large ≈300M; base ≈90M): 9 classes angry, disgusted, fearful, happy, neutral, other, sad, surprised, unknown; large fine-tuned on 42,526 h filtered pseudo-labelled data ("40k of 160k hours"); base on 4,788 h; seed on 201 h of EmoBox academic data; run via FunASR `AutoModel(model="iic/emotion2vec_plus_large")`, 16 kHz input, utterance or 50 Hz frame granularity; no accuracy numbers and no language list on the card; "model-license" — [emotion2vec_plus_large card](https://huggingface.co/emotion2vec/emotion2vec_plus_large)
- SenseVoice (FunAudioLLM, July 2024): emotion tags `<|HAPPY|>`, `<|SAD|>`, `<|ANGRY|>`, `<|NEUTRAL|>`, `<|FEARFUL|>`, `<|DISGUSTED|>`, `<|SURPRISED|>` (+ `emo_unk`); event tags `<|BGM|>`, `<|Speech|>`, `<|Applause|>`, `<|Laughter|>`, `<|Cry|>`, `<|Sneeze|>`, `<|Breath|>`, `<|Cough|>`; SenseVoiceSmall covers zh, en, yue, ja, ko only (no Turkish; the 50+ languages figure refers to the broader work); >400,000 h training; code MIT, weights under the FunASR model license, commercial use of official weights permitted with attribution (issue #334); >5x faster than Whisper-Small — [SenseVoice GitHub](https://github.com/FunAudioLLM/SenseVoice); SER evaluated on seven datasets incl. CREMA-D, MELD, IEMOCAP, MSP-Podcast where "SenseVoice-Large achieved the best performance on nearly all datasets"; AED compared to BEATs/PANNs on ESC-50 and baby cry/laugh with acknowledged "gaps compared to specialized AED models" — [FunAudioLLM paper](https://arxiv.org/html/2407.04051v1)
- Qwen2-Audio: MELD emotion accuracy ≈0.553 (another table in the same repo: 0.535), vs Qwen-Audio 0.557 and WavLM-large 0.542 — [Qwen2-Audio GitHub](https://github.com/QwenLM/Qwen2-Audio); [Qwen2-Audio report](https://arxiv.org/html/2407.10759v1)
- SALMONN scored 33.5% vs Qwen2-Audio-7B-Instruct 49.0% on a MELD-based sentiment task in Dynamic-SUPERB Phase-2 (LLM-judged) — [arXiv 2411.05361](https://arxiv.org/pdf/2411.05361); SALMONN's emotion responses were inconsistent under adversarial audio — [ACL Findings 2025](https://aclanthology.org/2025.findings-acl.884.pdf)
- Qwen3-Omni-30B-A3B-Captioner (Sept 2025): fine-tune of Qwen3-Omni-Instruct producing "detailed, low-hallucination captions for arbitrary audio", "identifying multiple speaker emotions, multilingual expressions"; audio-only, single-turn, no text prompt — [Qwen3-Omni Captioner card](https://huggingface.co/Qwen/Qwen3-Omni-30B-A3B-Captioner); [Qwen3-Omni report](https://arxiv.org/pdf/2509.17765); AEQ-Bench notes its speech-delivery captions "can be biased and overly positive regarding machine delivery" — [arXiv 2601.10513](https://arxiv.org/pdf/2601.10513)
- EmpathicInsight-Voice (LAION EmoNet, June 2025): frozen continually-pretrained Whisper-Small encoder + 40 MLP heads (one per emotion, ~74M Small / ~148M Large each) regressing 0–4 intensity, trained with MAE against Gemini Flash 2.0 scores; on EmoNet-Voice Bench Spearman/Pearson 0.415/0.421 (Large), 0.418/0.414 (Small), Gemini 2.5 Pro 0.417/0.416, GPT-4o Audio Preview 0.337/0.336 (27.59% refusals), Gemini 2.0 Flash 0.355/0.350, Hume Voice 0.274/0.231 (39.16% refusals); zero-shot on human speech: 70.6% EmoDB, 74.2% RAVDESS (below supervised baselines); models CC, code Apache 2.0 — [arXiv 2506.09827](https://arxiv.org/html/2506.09827); [laion/Empathic-Insight-Voice-Small](https://huggingface.co/laion/Empathic-Insight-Voice-Small); [LAION blog](https://laion.ai/blog/do-they-see-what-we-see/)
- Data-Speech (Parler) derives pitch/rate/noise/reverb bins and needs a gender column; one third-party paper used a separate gender classifier with F1 99.93% — [dataspeech GitHub](https://github.com/huggingface/dataspeech); [arXiv 2509.14627](https://arxiv.org/pdf/2509.14627)

**Non-verbal / laughter detectors**
- jrgillick/laughter-detection: checkpoints "trained on the Switchboard data set", AudioSet annotations for evaluation; PyTorch since Aug 2021; `segment_laughter.py --threshold 0.5 --min_length 0.2` outputs segments/TextGrid; MIT; metrics not on the README (Interspeech 2021 evaluation scripts) — [laughter-detection GitHub](https://github.com/jrgillick/laughter-detection)
- NonverbalTTS pipeline: BEATs audio tagger detects 10 NV types, then ASR, emotion classification and a fusion algorithm merge multiple annotators, followed by human validation — [alphaXiv NonverbalTTS](https://www.alphaxiv.org/abs/2507.13155); [arXiv 2507.13155](https://arxiv.org/abs/2507.13155)
- voc2vec (2025): foundation model for non-verbal vocalization classification, trained on open data, outperforms speech/audio foundation models on NV classification (paper CC BY-NC-SA 4.0) — [arXiv 2502.16298](https://arxiv.org/html/2502.16298v1)
- Fine-tuning Whisper/Wav2Vec2 to emit laughter and speech-laugh in transcripts "without substantially degrading WER" (Interspeech 2025) — [U. Twente](https://research.utwente.nl/en/publications/enhancing-transcripts-of-open-source-automatic-speech-recognition/); streaming ESPnet ASR effective for laughter/scream detection (APSIPA 2025) — [APSIPA PDF](https://www.apsipa.org/proceedings/2025/papers/APSIPA2025_P253.pdf)

**Dataset-scale pipelines**
- VoxCPM2: expressive utterances "first screened with lightweight emotion classifiers", then Step-Audio R1 and Gemini 2.5 Pro wrote free-form descriptions, then "dedicated expert classifiers checked gender, age, and emotion"; controllable data = tens of thousands of hours of open-source expressive speech + several thousand hours internal — [arXiv 2606.06928v1](https://arxiv.org/html/2606.06928v1)
- Higgs AudioVerse: ~10M h annotated by multiple ASR models + sound-event classifiers + in-house audio-understanding model — [higgs-audio-v2 card](https://huggingface.co/bosonai/higgs-audio-v2-generation-3B-base)
- Fish S2: staged pipeline of video captioning, speech captioning, voice-quality assessment and reward modeling — [arXiv 2603.08823](https://arxiv.org/abs/2603.08823)
- LAION Emilia-with-Emotion-Annotations: ~215.6k h (Emilia 101.7k + YODAS 113.9k) in EN 139.0k / ZH 50.3k / FR 8.8k / KO 7.5k / DE 7.2k / JA 2.8k hours, labelled by "models from the EmoNet suite" with 40 emotion scores + 14 (table lists 15) attributes (valence −3…+3, arousal 0…4, …) and a BUD-E Whisper caption per sample; split across 5 repos; no accuracy stated — [laion/Emilia-with-Emotion-Annotations](https://huggingface.co/datasets/laion/Emilia-with-Emotion-Annotations); Emolia is the companion set — [laion/Emolia](https://huggingface.co/datasets/laion/Emolia)
- EmoBox (Interspeech 2024): 32 SER datasets, 14 languages, 262,020 utterances, 294.4 h; 12 English, 3 Mandarin, 2 each French/German/Italian, others one dataset each; intra- and cross-corpus benchmarks; cross-corpus test sets were balanced using emotion2vec; Whisper-large-v3 ranked first on 23/32 datasets and WavLM-large top-3 on 31/32 (secondary summary) — [EmoBox GitHub](https://github.com/emo-box/EmoBox); [Interspeech PDF](https://www.isca-archive.org/interspeech_2024/ma24b_interspeech.pdf); [leaderboard](https://emo-box.github.io/leaderboard1.html)
- CosyVoice 3 uses emotion2vec-large-plus as the emotion-accuracy judge for its CV3-Eval — [arXiv 2505.17589v2](https://arxiv.org/html/2505.17589v2); IndexTTS2, EmoVoice and Higgs use emotion2vec embedding similarity — [arXiv 2506.21619](https://arxiv.org/html/2506.21619); [arXiv 2504.12867v3](https://arxiv.org/html/2504.12867v3)
- EmoVoice excluded disgusted/fearful/surprised from its recall metric "because of low recognition accuracy" of emotion2vec on those classes — [arXiv 2504.12867v3](https://arxiv.org/html/2504.12867v3)
- Human fine-grained emotion labels are noisy: EmoNet-Voice Bench inter-rater Cronbach's α = 0.14 across six psychology-trained raters — [arXiv 2506.09827](https://arxiv.org/html/2506.09827)

**Turkish-specific evidence**
- TurEV-DB CNN reached ~76% accuracy on 4 emotions (0–8000 Hz band), compared against human judges — [TurEV-DB (SLTU 2020)](https://aclanthology.org/2020.sltu-1.52.pdf)
- EmoBox's 14 languages include single-dataset languages, but whether Turkish is among them was not confirmed from the sources fetched — [EmoBox paper](https://www.arxiv.org/pdf/2406.07162)

### Inferences
- For an unlabeled Turkish multi-speaker corpus, the practical stack is: (1) emotion2vec+ large (language-agnostic SSL features, 9 classes, frame-level option) and/or EmpathicInsight-Voice (40 fine-grained intensities, valence/arousal) as screeners; (2) an open sound-event tagger (BEATs/PANNs-style, as in NonverbalTTS) or jrgillick's detector for laughter, plus SenseVoice event tags only as a secondary signal since its released checkpoint has no Turkish; (3) an open audio-LLM captioner (Qwen3-Omni-Captioner) for free-form style descriptions if instruct-style training data are wanted; (4) a small human-validated Turkish subset (TurEV-DB/TurES/BAUM-1) to calibrate thresholds and measure agreement, since no tool reports Turkish accuracy.
- Expect coarse classes (happy/sad/angry/neutral) to be reliable and fine classes (fear/disgust/surprise) unreliable — EmoVoice dropped exactly those three for low classifier accuracy, and CosyVoice 3 saw accuracy "drop significantly" for sad/angry when text is neutral.

### Gaps
- No tool reports Turkish SER accuracy; cross-lingual claims (emotion2vec, EmpathicInsight) rest on German/Bangla/English benchmarks only.
- emotion2vec+ card withholds data-engineering details and gives no accuracy figures; SenseVoice SER tables are only in an image.
- AudioBox captioning (Meta) and the Emilia-Pipe internals were not retrieved; LAION "Got Talent" generation details were not in the fetched EmoNet-Voice text (only that EmoNet-Voice Big was generated with GPT-4o Audio).
- Precision/recall of jrgillick laughter detector not on README (in Interspeech 2021 paper); Whisper-event-detection accuracy numbers not retrieved.

## KQ4. Existing expressive / emotional open datasets (sizes, licenses), including Turkish

### Takeaway

## KQ5. How much emotion-labelled data is needed to add emotion / non-verbal tags to a base model by fine-tuning?

### Takeaway
Public evidence spans three regimes: (a) tag/voice fine-tunes of LLM-TTS (Orpheus) work with ~50–300 utterances per speaker and ~3 h / ~500 tag instances to teach laughs and sighs; (b) adding a non-verbal/emotion capability to a strong base takes tens to ~200 hours (NonverbalTTS 17 h; IndexTTS2 135 h emotional subset; EmoVoice ≈240 h); (c) building instruction-following from scratch takes thousands of hours (CosyVoice 3: 5,000 h of 1M; VoxCPM2: tens of thousands of hours). No source gives a validated minimum for tags in a new language.

### Cited Findings
- Orpheus README: "You should start to see high quality results after ~50 examples but for best results, aim for 300 examples/speaker" (voice fine-tuning) — [Orpheus-TTS GitHub](https://github.com/canopyai/Orpheus-TTS)
- Unsloth: Elise is ~3 h, ~1,200 samples, ~328 MB, with 336 "laughs" and 156 "sighs"; "a few epochs on 3h of data may take 1-2 hours" on a Colab T4; the guide gives no minimum data figure for tags or for a new language; notebooks for Orpheus-3B, Sesame-CSM-1B, Spark-TTS-0.5B, Llasa-1B, Oute-TTS-1B; "any transformers compatible TTS model" (e.g. Dia) — [Unsloth TTS guide](https://unsloth.ai/docs/basics/text-to-speech-tts-fine-tuning); [Unsloth blog](https://unsloth.ai/blog/tts)
- NonverbalTTS: 17 h was enough for fine-tuned open models to reach parity with CosyVoice2 on NV fidelity — [arXiv 2507.13155](https://arxiv.org/abs/2507.13155)
- IndexTTS2: emotion refinement stage on 135 h (361 speakers) after 55K h pretraining — [arXiv 2506.21619](https://arxiv.org/html/2506.21619)
- EmoVoice: pretraining on ~3,234 h (VoiceAssistant, EN) + 6,418 h (Belle, ZH); emotional fine-tuning on ~200 h filtered Got Talent + ~40 h EmoVoice-DB (minus 100 test + 50 validation samples per emotion) — [arXiv 2504.12867v3](https://arxiv.org/html/2504.12867v3)
- CosyVoice 3: instruction-following data 1,500 h → 5,000 h ("over 100 types") within 1M h total — [arXiv 2505.17589v2](https://arxiv.org/html/2505.17589v2)
- VoxCPM2: "tens of thousands of hours" open-source expressive speech + "several thousand hours" internal annotated data for controllability — [arXiv 2606.06928v1](https://arxiv.org/html/2606.06928v1)
- Qwen3-TTS trains on >5M h but does not report the size of its instruction/voice-design subset — [arXiv 2601.15621](https://arxiv.org/html/2601.15621)
- CosyVoice 3 speaker SFT mixes target-speaker data with instruction data and masks speaker/style prompt fields randomly; polyglot SFT yields CER/WER <4% for most languages (JA ≈9%, KO ≈6%) — [arXiv 2505.17589v2](https://arxiv.org/html/2505.17589v2)
- Orpheus README warns synthetic audio yields worse voice fine-tunes — [Orpheus-TTS GitHub](https://github.com/canopyai/Orpheus-TTS)

### Inferences
- For a Turkish corpus the realistic plan is a two-level budget: a few hundred human-checked tag instances per non-verbal class (Elise scale) to bootstrap `<laugh>`/`<sigh>`-type tokens, and 20–150 h of automatically emotion-labelled multi-speaker speech (NonverbalTTS → IndexTTS2 scale) for coarse emotion conditioning; thousands of hours are only needed for free-form instruction following.
- Because all tag learning is in-transcript, the limiting factor is label precision rather than hours; a few hundred mislabeled laughs will teach the wrong token.

### Gaps
- No Fish-Speech/OpenAudio fine-tuning data-size report with emotion tags was found; no CosyVoice 2/3 community fine-tune reporting emotion-tag data amounts was found (only NonverbalTTS).
- No ablation on number of tag instances vs. tag reliability exists in any fetched source.

## KQ6. Evaluation: how are expressiveness and emotion accuracy measured?

### Takeaway
Three layers are standard in 2025–2026: (1) automatic emotion metrics via emotion2vec (cosine "emotion similarity", or classifier accuracy/recall, typically on happy/sad/angry only); (2) listening tests with split MOS dimensions (EMOS/SMOS/PMOS/QMOS, I-MOS/N-MOS, CMOS) and third-party vendors (Podonos); (3) audio-LLM-as-judge benchmarks — EmergentTTS-Eval (1,645 cases, pairwise vs gpt-4o-mini-tts, Gemini 2.5 Pro judge) and InstructTTSEval (APS/DSD/RP) — plus crowd Elo on the Artificial Analysis Speech Arena. LLM judges correlate only moderately with humans (EmoVoice: <50% sentence-level; EmpathicInsight ≈0.42 Spearman).

### Cited Findings
- emotion2vec-based metrics: IndexTTS2 emotion similarity 0.887, speaker similarity 0.836, WER 1.883%, EMOS 4.22±0.12, SMOS 4.24, PMOS 4.08, QMOS 4.18; natural-language control EMOS 3.786 vs CosyVoice2 3.339 (double-blind) — [arXiv 2506.21619](https://arxiv.org/html/2506.21619)
- CosyVoice 3 CV3-Eval emotion accuracy (emotion2vec-large-plus, happy/sad/angry): 0.5B text-related 0.92/0.70/0.72, text-unrelated 0.64/0.42/0.58; 1.5B 0.86/0.64/0.72 and 0.64/0.44/0.48; DiffRO-EMO (SER reward) 1.5B 0.98/0.68/0.84 and 0.98/0.50/0.68 but "can adversely affect pronunciation" — [arXiv 2505.17589v2](https://arxiv.org/html/2505.17589v2)
- EmoVoice: emotion similarity 0.9118, recall 0.424 (1.5B), WER 2.62, UTMOS 4.35; MOS 3.507 vs gpt-4o-mini-tts 3.598 vs GPT-4o-audio 4.350; GPT-4o-audio and Gemini-2.0-Flash as judges correlated <50% with human sentence-level ratings — [arXiv 2504.12867v3](https://arxiv.org/html/2504.12867v3)
- Higgs Audio v2: EmergentTTS-Eval win rate vs gpt-4o-mini-tts 75.71% (Emotions), 55.71% (Questions); ESD emotion similarity (emo2vec) 86.13 vs 82.84 for v1; Seed-TTS Eval WER 2.44 / SIM 67.70 — [higgs-audio-v2 card](https://huggingface.co/bosonai/higgs-audio-v2-generation-3B-base)
- EmergentTTS-Eval (NeurIPS 2025 D&B): 1,645 test cases over six categories (emotions, paralinguistics, foreign words, syntactic complexity, complex pronunciation, questions); pairwise model-as-judge against a baseline such as gpt-4o-mini-tts; "high correlation with human preferences" (authors' claim) — [arXiv 2505.23009](https://arxiv.org/abs/2505.23009); [GitHub](https://github.com/boson-ai/emergenttts-eval-public); Fish S2 reports 81.88% overall win rate with Gemini 2.5 Pro judge (vendor-reported) — [Fish S2 report](https://arxiv.org/pdf/2603.08823)
- InstructTTSEval (APS / DSD / RP): Qwen3-TTS-VD ZH 85.2/81.1/65.1, EN 82.9/82.4/68.4; Mimo-Audio-7B ZH 75.7/74.3/61.5; Hume EN 83.0/75.3/54.3; VoxInstruct ZH 47.5/52.3/42.6; CustomVoice ZH 83.0/77.8/61.2 vs GPT-4o-mini-tts 54.9/52.3/46.0, Gemini-flash 88.2/90.9/77.3 — [arXiv 2601.15621](https://arxiv.org/html/2601.15621); VoxCPM2 EN 84.2/83.2/71.4, ZH 85.2/71.5/60.8 (Gemini-TTS-Pro higher on APS/DSD), I-MOS 4.50 / N-MOS 4.48 vs Qwen3-TTS-VD N-MOS 4.61, 50 listeners — [arXiv 2606.06928v1](https://arxiv.org/html/2606.06928v1)
- Step-Audio-EditX: LLM-judge paralinguistic score 1–3 (1.91 → 2.89 after one edit) — [arXiv 2511.03601](https://arxiv.org/html/2511.03601v1)
- Chatterbox Turbo: Podonos third-party preference/naturalness/expressiveness tests vs ElevenLabs Turbo v2.5, Cartesia Sonic 3, VibeVoice 7B (numbers not on README) — [Chatterbox GitHub](https://github.com/resemble-ai/chatterbox)
- Arena: Artificial Analysis open-weights Provider-Voice leaderboard (Fish Audio Drama 3 Preview #1, Breeze TTS 2, Ming-3.0-tts, Fish S2 Pro 4th–5th in one snapshot) — [Artificial Analysis](https://artificialanalysis.ai/text-to-speech/leaderboard/provider-voice/open-weights); Eleven v4 reported at Elo 1,319 after 2026-09-28 launch (secondary blog) — [progressiverobot](https://www.progressiverobot.com/2026/09/28/eleven-v4-turbo-elevenlabs-tops-tts-arena/); several ranking blogs disagree on Elo values — [offlinetts](https://offlinetts.com/blog/tts-model-ranking-2026/)
- Human benchmark ceiling: EmoNet-Voice Bench expert inter-rater α = 0.14 for 40-class intensity — [arXiv 2506.09827](https://arxiv.org/html/2506.09827)
- SER tool benchmarks: EmoBox leaderboard ranks by mean weighted accuracy across 32 datasets — [EmoBox leaderboard](https://emo-box.github.io/leaderboard1.html)

### Inferences
- For a Turkish evaluation, emotion2vec+ cosine similarity to a Turkish reference set (e.g., TurES/TurEV-DB clips) is the only automatic metric that needs no Turkish-specific judge; audio-LLM judges have not been validated on Turkish and show positive bias.
- Report coarse 3–4 class accuracy (happy/sad/angry/neutral) plus a small CMOS/EMOS listening test with native speakers; fine-grained 40-class claims are not reproducible even by experts.

### Gaps
- InstructTTSEval's own paper (definitions of APS/DSD/RP, judge model) was not retrieved; only its use in Qwen3-TTS/VoxCPM2 tables.
- No Turkish-language TTS expressiveness benchmark or arena slice was found.
- Podonos report numbers for Chatterbox and the EmergentTTS-Eval human-correlation figure were not retrieved.

## KQ7. Practical guidance: obtaining emotion / non-verbal labels for an unlabeled Turkish multi-speaker corpus (synthesis of the above)

### Takeaway
No off-the-shelf tool is validated on Turkish; the defensible approach is an ensemble of language-agnostic screeners (emotion2vec+, EmpathicInsight-Voice, a sound-event tagger / laughter detector), optional audio-LLM captions (Qwen3-Omni-Captioner) for instruct-style descriptions, and a few-hundred-clip native-rater calibration set drawn from TurEV-DB/TurES or the corpus itself — mirroring how NonverbalTTS, VoxCPM2 and LAION built their labels.

### Cited Findings
- emotion2vec+ runs via FunASR on 16 kHz audio with utterance or 50 Hz frame granularity — [emotion2vec_plus_large](https://huggingface.co/emotion2vec/emotion2vec_plus_large)
- EmpathicInsight-Voice outputs 40 intensity scores plus attributes; code Apache 2.0, models CC — [arXiv 2506.09827](https://arxiv.org/html/2506.09827); [Empathic-Insight-Voice-Small](https://huggingface.co/laion/Empathic-Insight-Voice-Small)
- SenseVoiceSmall emits `<|Laughter|>`, `<|Cry|>`, `<|Breath|>`, `<|Cough|>` events but is trained for zh/en/yue/ja/ko — [SenseVoice GitHub](https://github.com/FunAudioLLM/SenseVoice)
- NonverbalTTS: BEATs tagging → ASR → emotion classifier → fusion → human validation — [alphaXiv](https://www.alphaxiv.org/abs/2507.13155)
- VoxCPM2: classifier screening → Step-Audio R1 / Gemini 2.5 Pro descriptions → expert classifiers for gender/age/emotion — [arXiv 2606.06928v1](https://arxiv.org/html/2606.06928v1)
- Data-Speech derives gender-relative pitch, rate, noise, reverb bins for description prompts — [dataspeech GitHub](https://github.com/huggingface/dataspeech)
- Unsloth: hand-annotate transcripts where audio contains the expression if tags are missing — [Unsloth TTS guide](https://unsloth.ai/docs/basics/text-to-speech-tts-fine-tuning)
- TurES has 7 categorical labels + VAD from 27 annotators; TurEV-DB has 4 classes — [TurES page](http://www.turesdatabase.com/page/dataset); [TurEV-DB](https://aclanthology.org/2020.sltu-1.52.pdf)

### Inferences
- Pipeline: (1) VAD/segment; (2) run emotion2vec+ (9-class + embedding) and EmpathicInsight-Voice (valence/arousal + 40 scores) per utterance, keep only agreements above a threshold for the 4 coarse classes; (3) run a laughter/NV detector (BEATs-style tagger or jrgillick) at frame level to insert `<laugh>`/`<sigh>`/`<breath>` tokens at time-aligned positions in the ASR transcript; (4) for gender/age attributes use Data-Speech-style pitch stats plus a gender classifier; (5) have native raters label 300–500 utterances to measure agreement with the automatic labels before training; (6) target Elise-scale counts (hundreds of instances per tag) and tens of hours of coarse-emotion-labelled data.
- Model choice follows from KQ1: if Turkish support out-of-the-box matters, start from VoxCPM2 (Apache 2.0, Turkish, instruct + voice design) or Chatterbox Multilingual (MIT, Turkish, knobs); if tag-style control and Unsloth-style fine-tuning matter, Orpheus-style LLM-TTS requires teaching Turkish and tags together.

### Gaps
- No published Turkish TTS fine-tune with emotion tags was found, so all data-size numbers above are extrapolated from English/Chinese reports.
